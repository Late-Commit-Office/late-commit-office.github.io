隐私声明

生效日期：2026年11月13日

一、术语

  • “本办”“我们”：晚点办，由网站运营者信息（Imprint，仅有英文版）所列个人运营。
  • “您”：访问本网站或使用本软件的任何人。
  • “本网站”：latecommitoffice.com。
  • “本软件”：《在册软件》所列程序。

二、数据控制者

就数据保护法而言，晚点办是本声明所述个人数据的控制者。

我们仅在运营本网站、回复来函与支持请求或履行法定义务所必需时处理个人数据。

处理的法律依据为我们运营本网站及回复来函的正当利益（GDPR 第 6 条第 1 款 (f) 项）。

联系方式：contact[at]latecommitoffice.com

三、本网站

  • 本网站不使用 Cookie，不做访问统计，不加载任何第三方脚本或字体。
  • 如您选择了外观主题，该选择保存在您设备上浏览器的本地存储中，不会发送给我们，您可随时清除。
  • 本网站由 GitHub Pages 托管。GitHub 会处理提供网站所必需的技术信息，例如您的 IP 地址、浏览器信息、所访问的页面及访问时间。详见 GitHub 隐私声明。

四、本软件

软件下载由 GitHub 提供，适用 GitHub 隐私声明。

gitid

gitid 完全在您的电脑上运行，仅按您的指示读写本地 Git 配置，不向我们或任何第三方传输任何信息。

HDR Shield

HDR Shield 完全在您的 Mac 上运行，仅向屏幕发送自定义伽马表，不收集任何数据，亦不向我们或任何第三方传输任何信息。

[卫星壁纸应用]

发布前补充。届时将写明影像提供方；该方会收到图像请求，因而可获知您的 IP 地址。

五、电子邮件

您来函时，我们仅将您的邮箱地址与来函内容用于回复。发往本办的邮件经 Cloudflare Email Routing 转发，该服务为投递而处理邮件。我们仅在回复来函、保留支持记录或履行法定义务合理所需的期限内保存来往邮件。

六、您的权利

根据包括 GDPR 在内的数据保护法，您可要求查阅、更正或删除您的个人数据，亦可反对或限制某些处理活动。如需行使上述权利，请致函 contact[at]latecommitoffice.com。您亦可向爱尔兰数据保护委员会（Data Protection Commission）投诉。

七、变更

本声明如有变更，将在本页公布并更新生效日期，同时记入《历史沿革》。

本声明中英文版本如有歧义，以英文版为准。
