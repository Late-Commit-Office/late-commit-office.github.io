HDR 视频和图片会把 Mac 屏幕推到远超周围内容的亮度，在暗处尤其刺眼。HDR Shield 常驻菜单栏，将 HDR 内容的亮度限制在屏幕的正常亮度以内。

目前支持 Mac 内置显示屏；外接 HDR 显示器的支持仍处于测试阶段，诚征测试者，请使用 GitHub 上的外接显示器反馈模板提交测试结果。手头没有 HDR 视频？可在 Pexels 免费下载，无需注册或付款。

HDR Shield 只做一件事：向屏幕发送自定义伽马表。不收集任何数据，不连接任何服务器。
